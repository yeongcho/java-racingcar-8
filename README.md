# java-racingcar-precourse

## 기능 목록

### 1. 사용자 입력 기능

- 경주할 자동차 이름을 입력받는다.

    - "경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)" 안내 문구 출력

    - Console.readLine()으로 문자열 입력받기

- 시도할 횟수를 입력받는다.

    - "시도할 횟수는 몇 회인가요?" 안내 문구 출력

    - Console.readLine()으로 숫자 입력받기

### 2. 입력 값 검증 기능

- 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시킨 후 애플리케이션은 종료

    - 자동차 이름이 비어 있는 경우 예외 발생

    - 자동차 이름이 5자 초과인 경우 예외 발생

    - 이름이 공백만 포함된 경우 예외 발생

    - 이동 횟수가 숫자가 아닌 값인 경우 예외 발생

    - 이동 횟수가 0 이하인 경우 예외 발생

### 3. 자동차 초기화 기능

- 입력받은 자동차 이름을 , 기준으로 분리한다.

- 각각의 이름으로 Car 객체를 생성한다.

- 모든 자동차를 리스트에 저장한다.

### 4. 자동차 이동 규칙 기능

- 0~9 사이 무작위 숫자를 생성한다. (Randoms.pickNumberInRange(0, 9))

- 숫자가 4 이상이면 자동차가 전진한다.

### 5. 차수별 실행 기능

- 매 시도마다 모든 자동차의 이동을 실행한다.

- 자동차 이동 후 현재 위치(“-” 개수)를 출력한다.

- 출력 예: pobi : --

### 6. 우승자 판별 기능

- 가장 많이 전진한 자동차(최대 거리)를 찾는다.

- 우승자가 여러 명일 경우 ,로 구분한다.

- 출력 예: 최종 우승자 : pobi, jun

### 7. 테스트 기능

- 이름 검증 테스트

- Car 클래스의 이동 조건 테스트

- 우승자 판별 로직 테스트 (단독 우승/공동 우승 케이스)
